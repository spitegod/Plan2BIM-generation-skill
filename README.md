# Plan2BIM generation skill

Скилл CADLift для переноса строительных узлов из DWG/DXF в детализированные 3D-модели. Включает накопленные правила моделирования, сохранение цветов, групп и свойств в GLB и загрузку проверенной модели в TN-Viewer через API.

## Установка

Склонируйте репозиторий и скопируйте **всю папку `cadlift`** в каталог скиллов вашей среды, например `~/.codex/skills/cadlift`. Не ограничивайтесь копированием `SKILL.md`: база знаний находится внутри `references`.

Вызов: «Используя скилл CADLift, создай модель по приложенному DWG». Затем приложите чертёж. FreeCAD, CADLift и средство преобразования DWG в DXF устанавливаются отдельно; скилл не содержит их исполняемых файлов. Пути к инструментам определяются на целевом компьютере.

## Состав

- [`cadlift/SKILL.md`](cadlift/SKILL.md) — инструкции и согласованные правила моделирования.
- [`cadlift/references/pvc-roof-installation.md`](cadlift/references/pvc-roof-installation.md) — применение базы монтажа, фотоэтапов и проверки углов.
- `cadlift/references/pvc-roof-knowledge/` — встроенная рабочая база: 51 карточка, 261 фотофрагмент, HTML-атлас, сводный текст, правила углов и два исходных PDF.
- `cadlift/references/source-archives/8. Узлы 3D.rar` — полный исходный архив базы, 509 файлов, без исключения вспомогательных материалов. Название архива не означает наличие готовых GLB/STEP: он содержит документы, фотографии и результаты анализа.
- `cadlift/references/source-documents/Промпт.docx` — исходные дополнительные требования пользователя.
- [`cadlift/references/tn-viewer-upload.md`](cadlift/references/tn-viewer-upload.md) — контракт API и проверка загрузки в коллекцию.
- [`bundle-manifest.json`](bundle-manifest.json) — размеры и SHA-256 файлов комплекта для проверки целостности.

Рабочая база уже распакована и пригодна к использованию; распаковывать исходный RAR для обычной работы не требуется. Все ссылки базы разрешаются относительно папки скилла, без зависимости от расположения исходных файлов на компьютере автора.

## Результат и доступ к просмотрщику

По умолчанию скилл сохраняет GLB локально и загружает его в личную коллекцию TN-Viewer. STEP создаётся по явному запросу. Каждый пользователь предоставляет собственный API-токен в текущем чате; токены в репозитории не хранятся. Если токена нет, скилл запрашивает его, продолжая независимую работу над локальной моделью.

Данные базы объясняют монтаж и пространственное устройство деталей. Геометрию и состав конкретного исполнения определяют приложенные чертежи и указания пользователя. Скрытые восстановленные параметры отмечаются отдельно от подтверждённых размеров.
